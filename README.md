# Job Scheduler (Full Stack Project)

A full-stack Job Scheduler application that allows users to create jobs, manage priorities, track job status, and trigger webhooks when jobs are executed.  
Built using **React (Frontend)**, **Node.js + Express (Backend)**, and **MySQL (Database)**.

---

## 🚀 Features

- Create jobs with task name, payload, and priority
- View all jobs in a table format
- Filter jobs by status and priority
- Execute jobs manually
- Update job status (`pending`, `running`, `completed`, `failed`)
- Trigger webhook on job execution
- REST API based architecture
